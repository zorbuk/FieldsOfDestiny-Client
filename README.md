# Fields of Destiny - Android

1. Descarga **FieldsOfDestiny.apk** desde esta rama (`android`) en el móvil.
2. Ábrelo e instálalo. Si el móvil lo pide, permite instalar apps de origen desconocido.
3. Abre el juego. La primera vez descarga los recursos (unos cientos de MB, mejor con wifi). Después se actualiza solo.

Se juega en horizontal. Hace falta Android 7 o superior, de 64 bits.
Si el juego pide una versión nueva, descarga de aquí el APK otra vez e instálalo encima. No se pierde nada.

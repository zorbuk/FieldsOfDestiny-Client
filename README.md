# Fields of Destiny - cliente

El juego, listo para jugar en Windows (64 bits). No hace falta instalar nada.

1. Descarga el repositorio y descomprímelo donde quieras.
2. Abre `FieldsOfDestiny.Client.exe`.

El juego se actualiza solo cada vez que se abre.
Si algo falla: Opciones -> **Reparar el juego**.

`servidor.json` guarda la dirección del servidor.
Las actualizaciones no deben sobrescribir la configuración personal.

Los recursos OGG se distribuyen en `assets.rar`.
El actualizador debe extraerlos antes de iniciar el juego.

Tus opciones y teclas están en:
`%LOCALAPPDATA%\FieldsOfDestiny`

Este repositorio contiene únicamente el cliente compilado y sus recursos.

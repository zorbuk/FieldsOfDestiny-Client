# Fields of Destiny - cliente

El juego, listo para jugar en Windows (64 bits). No hace falta instalar nada.

1. Descarga: botón **Code → Download ZIP** (o `git clone`) y descomprímelo donde quieras.
2. Abre `FieldsOfDestiny.Client.exe`.

El juego se actualiza solo cada vez que se abre. Si algo falla: Opciones → **Reparar el juego**.

`servidor.json` guarda la dirección del servidor (se puede cambiar para jugar en otro); las actualizaciones nunca
lo sobrescriben. Tus opciones y teclas están en `%LOCALAPPDATA%\FieldsOfDestiny`.

Este repositorio solo contiene el cliente compilado y sus recursos (créditos de los recursos en la web del juego).

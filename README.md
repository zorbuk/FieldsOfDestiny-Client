# Fields of Destiny - cliente

El juego, listo para jugar en Windows (64 bits). No hace falta instalar nada.

1. Descarga el repositorio (Code -> Download ZIP) y descomprímelo donde quieras.
2. Abre `FieldsOfDestiny.Client.exe`.

La primera vez prepara los recursos (los paquetes de `paquetes/`, que se borran al extraerse).
El juego se actualiza solo cada vez que se abre: solo descarga lo que ha cambiado.
Si algo falla: Opciones -> **Reparar el juego**.

`servidor.json` guarda la dirección del servidor. Las actualizaciones nunca la sobrescriben.

Tus opciones y teclas están en `%LOCALAPPDATA%\FieldsOfDestiny`.

Este repositorio contiene únicamente el cliente compilado y sus recursos.

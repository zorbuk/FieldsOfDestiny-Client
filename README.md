# Fields of Destiny - cliente para Linux (64 bits)

1. Descarga esta rama (`linux`): Code -> Download ZIP, y descomprímelo donde quieras.
2. Abre una terminal en la carpeta y ejecuta: `sh jugar.sh`

La primera vez descarga y prepara los recursos del juego. Después se actualiza solo cada vez que se abre.
Si algo falla: Opciones -> **Reparar el juego**.

Necesitas OpenGL 3 (los controladores de tu tarjeta gráfica). La voz por proximidad usa Discord (se vincula desde el juego).
Tus opciones y teclas están en `~/.local/share/FieldsOfDestiny`.
